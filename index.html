Hardened

A single static page with a deny-by-default CSP, a 150 KB weight budget, and CI that fails the build when either regresses.

  • Performance

    Lighthouse 100. 34 KB on a cold load, LCP 0.3 s, CLS 0. A budget check caps the critical path at 150 KB and any one file at 200 KB.

  • Security

    No JavaScript at all, so the policy is default-src 'none' with no unsafe-inline. HSTS, COOP/COEP/CORP, and 11 header assertions on every push.

  • Accessibility

    Lighthouse 100. Text contrast above 9:1, hover motion dropped under prefers-reduced-motion, semantic landmarks throughout.
